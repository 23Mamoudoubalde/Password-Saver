🔐 Forteresse Digital - Password Manager

A simple and secure password manager built with Python and Tkinter. It allows users to generate strong passwords, save login details locally using JSON, and retrieve them with ease. Clipboard functionality and a clean UI make it beginner-friendly and practical.

 

🚀 Features

✅ Generate strong, randomized passwords

✅ Copy password to clipboard automatically

✅ Save and store login details securely in a local JSON file

✅ Search for saved credentials by website

✅ Simple and responsive Tkinter GUI

🛠️ Technologies Used

Python 3

Tkinter (built-in GUI library)

JSON (for data storage)

pyperclip (to copy passwords)
